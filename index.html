Bujhau (@BujhauNepali) is an independent Nepali-language education channel for Nepali people living in Japan. We publish original explainer videos about Japanese visas, taxes, pensions, insurance, culture and history.

Bujhau Uploader

Bujhau Uploader is a small private desktop tool used only by the channel owner. It runs on the owner's own computer and uploads the channel's own videos:

  • to YouTube, using YouTube API Services (title, description, privacy status, schedule, thumbnail, Nepali subtitles, AI disclosure);
  • to TikTok, using TikTok Login Kit and Content Posting API (caption, privacy level, AI-generated content label).

The tool has no other users, no server and no database. See the Privacy Policy and Terms of Use.
